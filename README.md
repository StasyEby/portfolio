
# Explainable Loan Decision Engine

## Project Overview

This project explores the application of Explainable Artificial Intelligence (XAI) to loan approval prediction.

It demonstrates how machine learning can support loan decision-making while providing explanations that help users understand the factors influencing model predictions.

## Business Problem

Machine learning models used in financial services can produce predictions that are difficult to interpret.

In lending environments, understanding why a loan application receives a particular prediction is important for transparency, accountability and informed decision-making.

## Project Objectives

- Develop a machine learning model for loan approval prediction.
- Evaluate model performance.
- Apply Explainable AI techniques.
- Identify the features influencing model predictions.
- Explore how model explanations can support transparent lending decisions.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- SHAP
- Matplotlib
- Google Colab

## Explainability Techniques

The project explores:

- SHAP feature importance.
- SHAP waterfall explanations.
- Global feature importance.
- Individual prediction explanations.

## Key Findings

The analysis identified loan amount as an important contributing feature in the model's explanations.

SHAP visualisations were used to examine how individual features influenced predictions.

## Project Deliverable

The accompanying Jupyter Notebook contains the implementation, model evaluation and explainability analysis.

## Important Disclaimer

This is an educational and portfolio project. Its predictions are not intended for actual credit approval or lending decisions.
